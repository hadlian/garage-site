Two kinds of fact, kept apart. In file and Decoded from the file are parsed — open a different tune and they follow. ECU Manager is typed by a human from the vendor tool, because the M800 carries not one channel, sensor or output name as text. 0 of 30 slots have been read off the tool so far.

Auxiliary outputs

The one table the file does give up. Each byte stores the function number — directly for functions 0–9, the function minus 90 for the 100-series (0x0B is 101, Fuel Pump). Zero is an output never configured; a deliberately selected Off stores 1, which Boost Control (function 1) also would — the encoding’s one open edge. All eight pinned 2026-08-09: aux 5 by its controlled edit, the rest by the Auxiliary Output Functions submenu naming each output's current function against the stored bytes.
