M800 mapping checklist — IO and communications

Nine items in ECU Manager. Items 5 and 9 need no save at all — they are readings, and they are the cheapest things on this list. If you are only opening ECU Manager once, do the three in the block below and nothing else.

Nothing here touches the fuel or ignition tables except item 6, which touches exactly one cell of one on purpose, and item 8, which reshapes an axis and must never be sent to the ECU.

Do these three first — two readings and one save

Everything else on this list is optional; these three are not, because each one closes a question that currently makes the parser or the schematic say something it cannot support. Between them they are about fifteen minutes with ECU Manager open. Items 1 and 2 need no save at all. Item 3 is one Save As.

Protocol

  1. Always start from the same baseline — source/Z4 config 12_19_25test.e35. Never chain edits off a previous test file: Z4 SensorTest.e35 was chained off Z4 DigTest.e35 and had to be isolated by diffing against that instead of the baseline. Save new tunes into source/m800-tunes/.
  2. Give every field in a save a DIFFERENT value. The diff shows one run per field; you match run to field by the value you typed. Same value twice and the two runs become indistinguishable.
  3. Write down what each field read BEFORE you change it. The before/after pair is what pins an ENCODING rather than merely locating a byte — save 7's 2.5 stored as 0x05 is what gave Ign AT Comp its s8 x0.5 scale, which the after value alone could not. But one pair is not always enough, and the aux table is the standing warning: aux 5's 101-to-0 pair (0x0B to 0x01) fits the function-number rule AND the retired list-position rule equally well, because 101 - 90 and 101's index in the function list are the same number. When a single anchor can be read two ways, record both readings and get a second anchor — see encodings.aux_function.
  4. Save As a new filename. Do not overwrite, do not send to the ECU.
  5. One save per section, then run the diff before moving on.

After each save:

python cars/z4/tools/diff_e35.py "cars/z4/source/Z4 config 12_19_25test.e35" "cars/z4/source/m800-tunes/<newfile>.e35" --survey cars/z4/source/m800-tunes --map formats/e35_map.json --record "save 1 - digital inputs"

Save 3 — Auxiliary outputs — confirm the function-number rule, and settle Off vs Boost Control

Screens: Aux Output Setup

Partly done. Largely superseded 2026-08-09: the Auxiliary Output Functions submenu named all eight outputs against the stored bytes, which pinned the run to aux 1 and settled the encoding — see encodings.aux_function. What this save is still worth is the last row: no output on this car uses Boost Control (function 1), and a selected Off also stores 0x01, so those two states are indistinguishable in the file until one edit separates them.

Item 9 — Read one cell to settle the Ign MAP Comp scale — no save needed

Screens: Adjust > Ignition > Compensations > MAP, with Z4 IgnComps.e35 open

OPEN THE RIGHT FILE. The value that decides this exists only in source/m800-tunes/Z4 IgnComps.e35, where save 7 put it — 0x01 at 0x0469D. The car's own tune reads 0x00 there and would settle nothing. Save 7 typed 1.5 into the first cell and the file stored 1, which is consistent with two different readings and they disagree by a factor of two: either the field is integer-degrees like Gear Comp and Ign Comp 1/2 (so 1.5 snapped to 1, scale x1), or the scale is s8 x0.5 like Fuel AT Comp and Ign AT/ET Comp (so the stored 1 means 0.5). The parser currently assumes x0.5. While you are on this screen the other three save-7 cells are worth a glance too — they are already confirmed and should read back exactly as typed.

→ If it reads 1, calibration_tables.tables['Ign MAP Comp'].scale changes 0.5 -> 1 and every value that table has ever reported was half its real size. That is the only live way this map is currently WRONG rather than merely incomplete, which is why it leads the next-trip list.

→ If any of the three confirmation rows disagrees with its expected value, stop and write down all four — that would mean the save-7 attribution is wrong, not just the scale.

Note. Alarms are barely an M800 feature and maths channels are not a feature of either box. The M800 has User Channel 1-8, engine-protection limits, Aux Tables and the Driver Warning Alarm aux function; the C1212 has real alarms but no user-programmable arithmetic. A computed value that needs to reach the dash must be built in the ECU and sent over CAN. Note. Item 5 is free and item 6 costs one save. Between them they are worth more than the other four combined: one resolves every unnamed channel on the schematic, the other opens the part of the file nothing has read.
