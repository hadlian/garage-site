Protocol

  1. Always start from the same baseline copy of C1212 Alsense.c1212v64. Never chain edits.
  2. Give every field in a save a DIFFERENT value, so runs can be matched to fields by value.
  3. Write down what each field read BEFORE changing it — that is what decodes the field, not just locates it.
  4. Save As a new filename. Do not send to the dash.
  5. Run the diff after each save before moving on.

After each save:

python cars/z4/tools/diff_e35.py "cars/z4/source/C1212 Alsense.c1212v64" "cars/z4/source/<new>.c1212v64" --map formats/c1212_map.json --record "save 1 - display page"

Save 3 — Harvest a built-in channel id

Screens: CAN / communications — a transmit template

Now that word 9 of a +0x00EA record is known to be the source channel id, any built-in channel's id can be read off by putting it in a CAN message. This converts 'the id table is inside Dash Manager' into something answerable one channel at a time. Bind two built-ins whose ids are unknown to two free bytes of an existing transmit template.

→ Repeat for as many built-ins as matter; each save is cheap.
