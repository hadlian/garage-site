Comparison with stock

The car's template compared with the same selection exported from a stock read, by parameter ID. This is an evidence record, not a tune recommendation.

Validation

VCM Editor's Calibration Details show both files are the same car: a 2017 Corvette Grand Sport 6.2 L, E92A hardware, OS 12678648, with identical segment IDs. The Main OS CVN matches. The stock file is believed to be the original untouched read of this car; that provenance is stated, not proven by the files. The stock export itself is not held here.

All five calibration segment CVNs differ from stock, while this comparison covers only the 309-record Torque Model and Torque Management selection. VCM Editor's Compare function lists 126 changed names across the tune, so the 25 records below are not a complete list of what changed. The other 101 are in 04-wider-comparison.md.

Matching stock

Ceiling-like values 12820, 12872, 32923, 27389, 23618, 9509–9516 and scalars 2807, 2808, 2811–2815, 23570, 23594, 23595 match stock, so a ceiling value alone is not evidence of tuning. So do 25017 (Maximum MAP), 26590 (Use Axle Torque), 32433, 19049 and 33460.

ECM torque intervention and EBCM brake intervention

  • ECM torque intervention is in these files. 2861 gates TCS torque reduction by coolant temperature and differs from stock. 2869 scales the delivered-torque signal to the TCS system and differs from stock. 289 lets TCS events disable brake torque management and matches stock. 295 Powerhop Master, the master switch for wheel hop control, differs from stock.
  • EBCM brake intervention is not in these files. Neither template holds EBCM calibration, so this comparison says nothing about whether wheel braking differs from stock. Brake Torque Limit is an ECM parameter limiting engine torque under braking, not EBCM wheel braking.

Interpretation

None of this is confirmed, and none of it supports changing a calibration value.

  • 2861: read with its description, stock allows ECM torque reduction for TCS from −40 upward, effectively always, while the tune's value keeps it from being allowed in normal operation. −40 is the same in °C and °F. Whether the EBCM's torque requests are then ignored needs logs.
  • 2869: stock's 650 is close to the LT1's rated torque. The tune's is about 12.6 times larger, so if the signal scales as the description says, it would read far lower for the same torque.
  • 295: wheel hop control is off in the tune and on in stock, if the enumeration means what its description says. What that does on the car needs logs.
  • 2850: at 8191 the enable threshold is probably out of reach, so Fast Torque Exit would rarely or never activate.
  • 32924: whether an overboost limit does anything on this naturally aspirated engine is not established, so the size of this change may overstate its effect.
  • 32920: this is the peak indicated torque value, so it may feed the torque model rather than limit output.
  • 33050 and 33051: stored 655.70 against 363.00 in the 100 % row suggests a higher engine-torque request at full pedal than stock. Whether the engine delivers it depends on other limits and needs logs. Don't quote these in N m or lb-ft.
  • The grid tables: low-rpm changes in one row could be torque-model changes for the cam.
