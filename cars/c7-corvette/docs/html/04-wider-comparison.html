Wider comparison with stock

The tune compared with the same selection from the stock file, by parameter ID. This record covers the 101 parameter names selected in the wider template outside the torque template. It is an evidence record, not a tune recommendation, and nothing here supports changing a calibration value.

The first three sections are kept apart on purpose: what is confirmed, what is inferred, and what is unresolved. The last two list the names the template covers and how each was confirmed.

12050 is a confirmed +600 rpm change. It is separate from RPM Limit Extreme Cutoff (2068), which VCM Editor displays as 6700 rpm in the stock file, with RPM Limit Extreme Resume (2069) at 6620 rpm. Those match the stored stock values; the tune stores 7300 and 7220.

Stock gear ratios

The stock file's displayed ratios match Chevrolet's published Grand Sport seven-speed manual specifications (Chevrolet Grand Sport technical data), and they match the parser. An earlier concern that these looked like base-gearbox ratios was a mistake.

This supports the file being appropriate for a Grand Sport. It does not prove the file is untouched: it stays believed to be the original untouched read of this car.

Export artefacts, not calibration

Two differences change between exports of the same stock tune, so they are not calibration differences:

  • scalar 20005's trailing byte, 0 or 150; its value difference below is real
  • table 12171's row label, Boundary RPM DoD with or without a leading space

Inferences

None of these is confirmed.

  • Uniform changes: the same offset or multiple across a whole table looks deliberate. The names say what each parameter is, but not why it was changed or whether it is active in this application.
  • 20090 columns 8 to 10: treated as unused or default slots, because the car has seven speeds. Stock holds 0.478, 6000 and 3.88e−28 there; the tune holds 0.454, 0.45 and 0.45.

Unresolved

  • Tune-side ratios. Trans Gear Ratios For Speed Matching (20265) holds 2.289, 1.611, 1.208, 1, 0.818, 0.675, 0.454 in the tune, which match none of the published sets found. Trans Gear Ratios (20090), Trans Gear Ratios Min (20261), Trans Gear Ratios Max (20262) and Upper N/V Ratio Limit Per Gear For Clutch Slip Diagnostics (20855) also differ from stock. In the tune, 20090's 5th and 6th (0.813, 0.672) differ from 20265's (0.818, 0.675); in stock the two tables agree. The names and stored differences are confirmed; why the values differ is unknown. The tune filename contains "RATIO FIX", but no link is established.
  • Trans Reverse Gear Ratio (20005). 3.16 in the tune and 3.27 in stock. The name is confirmed; why the value differs is unknown.
  • Stock-file history. The stock file is believed to be the original untouched read of this car. The files do not prove that.
  • Why values differ. All 100 records are now named, but a name does not establish the tuner's intent or whether the parameter is active in this application.
  • The 16 downgraded candidates. Record order varies between exports. See 03-stock-comparison.md.

How the mapping was confirmed

A binding is confirmed when either of these is true:

  1. VCM Editor displays the parameter name and [ECM] ID together.
  2. A single-parameter .htt export parses to exactly one ID.

A single-parameter export holding no records confirms nothing. Every binding here used method 1: 12050 and 20090 in VCM Editor's normal view on 6 Nov 2026, and the other 99 in its Template Editor on 7 Nov 2026. Neither method changes a calibration value.
