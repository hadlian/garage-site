Wider comparison with stock

The tune compared with the same selection from the stock file, by parameter ID. This record covers the 101 changed names outside the torque template. It is an evidence record, not a tune recommendation, and nothing here supports changing a calibration value.

The first three sections are kept apart on purpose: what is confirmed, what is inferred, and what is unresolved. The last two list the names the template covers and how each is confirmed.

12050 is a confirmed +600 rpm change. It is separate from Extreme Cutoff, which VCM Editor displays as 6700 rpm in the stock file, with Extreme Resume at 6620 rpm.

Stock gear ratios

The stock file's displayed ratios match Chevrolet's published Grand Sport seven-speed manual specifications (Chevrolet Grand Sport technical data), and they match the parser. An earlier concern that these looked like base-gearbox ratios was a mistake.

This supports the file being appropriate for a Grand Sport. It does not prove the file is untouched: it stays believed to be the original untouched read of this car.

Inferences

None of these is confirmed.

  • Uniform changes: the same offset or multiple across a whole table looks deliberate. What each table does stays unknown until it is named.
  • Scalars 2068 and 2069: they hold 6700 and 6620 in stock, the values displayed for Extreme Cutoff and Extreme Resume, and 7300 and 7220 in the tune. They match by value only and stay unbound.
  • 20090 columns 8 to 10: treated as unused or default slots, because the car has seven speeds. Stock holds 0.478, 6000 and 3.88e−28 there; the tune holds 0.454, 0.45 and 0.45.

Unresolved

  • Tune-side ratios. ID 20265 is unbound. In the tune it holds ratio-like values, 2.289, 1.611, 1.208, 1, 0.818, 0.675, 0.454, which match none of the published sets found. It is not identified as a particular gear-ratio parameter until independently confirmed. Tables 20090, 20261, 20262 and 20855 also differ from stock. In the tune, 20090's 5th and 6th (0.813, 0.672) differ from 20265's (0.818, 0.675); in stock the two tables agree. The stored differences are confirmed; why they exist is unknown. The tune filename contains "RATIO FIX", but no link is established.
  • Scalar 20005. 3.16 in the tune and 3.27 in stock. It stays unbound and is not assumed to be an axle ratio.
  • Stock-file history. The stock file is believed to be the original untouched read of this car. The files do not prove that.
  • Everything else. Apart from 12050 and 20090, the 100 records have no confirmed name. The other 99 names in the names export stay unbound and are not joined by position.
  • The 16 downgraded candidates. Record order varies between exports. See 03-stock-comparison.md.

Completing the mapping

A binding becomes confirmed when either of these is true:

  1. VCM Editor displays the parameter name and [ECM] ID together.
  2. A single-parameter .htt export parses to exactly one ID.

A single-parameter export holding no records confirms nothing, and the name stays unbound. Neither method changes a calibration value.
