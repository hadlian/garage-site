# garage-site

Documentation for three race cars, generated by reading the devices in them
rather than by describing the devices from memory.

**https://hadlian.github.io/garage-site/**

| | |
|---|---|
| BMW E46 M3 | MoTeC M150 ECU, AiM PDM32 |
| BMW Z4 | MoTeC M800 ECU, MoTeC PDM, MoTeC C1212 dash + E888 |
| BMW E46 M3 (Canada) | EMTRON ECU logged over CAN, AiM MXG 1.2 dash |

The two E46 M3s are **different vehicles** and nothing shown for one is
evidence about the other. The pages say which car they are about, and the
Canada car's page says how little about it is established: it is two files, a
dash configuration and one session log, and everything on that page traces to
one of them.

Each page is self-contained — no network, no toolchain — because what it is
for is being opened on a phone in a garage.

## Nothing here is written by hand

Every file in this repository is output. The pages are built from the cars'
own configuration exports by parsers that read the actual bytes, and pushed
here by `garage.py publish` from a private repository that holds the exports,
the harness data and the logged run data.

So don't edit anything here: the next publish overwrites it. `VERSION` names
the exact private-repo commit the current pages were built from, and no page
is published unless every one of them rebuilds byte-identically from its
inputs first.

## What the confidence words mean

The pages say how far to trust each thing they show, because much of this was
recovered from undocumented binary formats by controlled edit — change one
setting in the vendor tool, save under a new name, diff:

- **confirmed** — proven by a controlled edit or an anchor
- **probable** — location solid, meaning inferred
- **candidate** — located, not proven

Where two sources disagree, both are shown and the disagreement is reported
rather than resolved. Where something is unknown it says so; a page that
looked complete while quietly missing a section would be worse than no page.
